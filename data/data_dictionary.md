# 欄位說明

| 欄位名稱 | 欄位說明 | 備註 |
|---|---|---|
| `Id` | 行程編號 | 唯一值 |
| `RiderId` | 乘客編號 | |
| `OrderStartDateTime_UTC8` | 行程開始時間 | |
| `OrderEndDateTime_UTC8` | 行程結束時間 | |
| `PickUpLatitude` | 上車緯度 | |
| `PickUpLongitude` | 上車經度 | |
| `DropOffLatitude` | 下車緯度 | |
| `DropOffLongitude` | 下車經度 | |
| `TravelTime` | 行駛分鐘數 | |
| `TravelDistance` | 行駛公尺數 | |
| `OrderFormCreatedTime_UTC8` | 叫車時間 | |
| `PickUpLocationType` | 上車地點 POI | 含乘客自定義的 POI |
| `DropOffLocationType` | 下車地點 POI | 含乘客自定義的 POI |
| `PaymentTotalRange` | 乘車金額區間 | `[100,200]` 表示區間為 101~200 |
